# Project Recall — StockForge

## One-line explanation
React + Express inventory system for stock management, roles, categories, soft deletion, history and dashboards.

## Main technical pieces
- React/Vite
- Express
- Prisma
- PostgreSQL/SQLite configuration
- JWT
- bcrypt
- Stock logs
- Soft deletion and restore

## Interview questions
1. Why use soft delete for inventory records?
2. How should stock changes be audited?
3. Why separate frontend and backend?
4. How does Prisma map application models to the database?
5. How would you prevent two users from corrupting stock counts concurrently?
